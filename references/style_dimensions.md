# Style dimensions checklist

Go through every item while watching the contact sheets. Write down a concrete value for each.

## Visual
- **Format**: resolution, fps, aspect ratio, safe margins.
- **Palette**: background colours per section, accent colours, how many colours per frame, saturation level, dark vs light base.
- **Rendering style**: flat / gradient / textured / 3D / footage; outlines yes/no and stroke width; corner roundness; shadows (hard, soft, long); highlights.
- **Shape language**: geometric vs organic, recurring primitives, detail density (sparse vs busy), scale of objects vs frame.
- **Characters**: proportions (head:body), eyes/mouth design, limbs, how emotion is shown, how they move (squash/stretch, bounce).
- **Backgrounds & depth**: layers of parallax, atmospheric perspective, fog, particles, stars.
- **Texture layer**: grain, noise, paper, vignette, bloom/glow, chromatic aberration.
- **Typography**: font family (or nearest free match), weights, sizes at 1080p, case, letter-spacing, colour, how text enters/exits, captions yes/no.
- **Icons / infographics**: chart style, arrows, labels, number styling.

## Motion
- **Easing**: snappy (easeOutBack/Expo) vs smooth (easeInOutSine); overshoot amount.
- **Typical durations**: element in/out (frames), hold time, transition length.
- **Camera**: static vs constant slow drift; zooms, pans, push-ins on reveals; whip pans.
- **Transitions**: hard cut, match cut, zoom-through, morph, wipe; which one is used when.
- **Secondary motion**: idle wobble, breathing, floating, blinking.
- **Rhythm**: avg shot length, cuts/min, how many visual changes per sentence.

## Audio
- **Narrator**: gender/age feel, pitch, energy, wpm, pauses between sentences, mic sound (dry/warm/roomy).
- **Music**: genre, instrumentation, tempo, how loud vs voice, where it swells/drops, silence moments.
- **SFX**: density, types (whooshes, pops, clicks, ambiences), cartoony vs realistic.
- **Loudness**: integrated LUFS, true peak.

## Writing / Structure
- Hook: length in seconds, type (question, shocking fact, "imagine…").
- Section structure and length, chapter titles, recaps.
- Sentence length, tone (dry, playful, dramatic), humour type and frequency.
- Recurring phrases or formats; call to action; outro / end card length and layout.
